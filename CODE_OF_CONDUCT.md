# Code of Conduct

We want OmniRoute to be a respectful, welcoming, and constructive project.

Expected behavior:
- Be kind and respectful.
- Critique code and ideas, not people.
- Give actionable feedback.
- Respect privacy and keep personal information confidential.
- Welcome contributors of all experience levels.

Unacceptable behavior includes harassment, discrimination, threats, personal attacks, and publishing private information without permission.

Report conduct concerns privately to the repository maintainer through GitHub. The maintainer will review reports fairly and may remove content or restrict participation when necessary.
